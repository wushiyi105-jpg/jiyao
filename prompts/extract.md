# 会议待办抽取

从会议转写里抽出**待办**与**决议**。只抽转写里明确说过的内容，不要推测。

输出 JSON：
```json
{
  "actions": [
    {"text": "一句话描述要做的事", "assignee": "人名或空字符串", "due": "YYYY-MM-DD 或 null", "quote": "转写里的原句"}
  ],
  "decisions": [
    {"text": "一句话结论", "quote": "转写里的原句"}
  ]
}
```

规则：
1. `quote` 必须是转写里的**连续原文**，一字不改；找不到原文的条目不要输出。
2. `assignee` 只填明确出现的名字，没有就留空，不要猜。
3. `due` 只在有明确日期时填；"下周""月底"这类模糊说法换算成具体日期，换算不了填 null。
4. 不要输出寒暄、复述、总结。
